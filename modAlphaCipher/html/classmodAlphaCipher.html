Подробное описание

Шифр Виженера для русского алфавита.

Каждой букве текста прибавляется буква ключа по модулю длины алфавита. Ключ повторяется, пока не закончится текст. Работаем только с буквами, регистр приводим к верхнему, остальные символы игнорируем.
